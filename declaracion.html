01

Declaración de uso de inteligencia artificial

Para realizar este proyecto utilicé herramientas de inteligencia artificial como apoyo durante el proceso de creación de la página web.

La inteligencia artificial me ayudó principalmente a organizar algunas ideas, mejorar la estructura del código HTML y crear el código CSS y JavaScript utilizado en la página.

También la utilicé como apoyo para revisar algunos textos y comprender mejor determinados conceptos relacionados con la biotecnología.

El contenido fue revisado y seleccionado para adaptarlo al objetivo del proyecto y al nivel de la materia.

🤖

La IA como herramienta

La inteligencia artificial fue utilizada como una herramienta de apoyo y no como reemplazo del trabajo realizado durante el proyecto.

03

Tecnología de implementación

Para implementar y publicar este sitio se puede utilizar GitHub Pages, un servicio que permite alojar páginas web creadas con HTML, CSS y JavaScript.

Elegí esta opción porque el proyecto está formado por archivos simples y no necesita una base de datos ni un servidor complejo para funcionar.

Además, permite organizar los archivos del proyecto y acceder a la página desde un navegador mediante un enlace.

💻
